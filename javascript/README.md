# JavaScript and Web Development Practice Files

This folder is organized into subfolders by topic so the exercises from your assignment list are easier to study and run.

## Structure

- `javascript/dom-manipulation/` – DOM manipulation examples
- `javascript/events/` – event handling examples
- `javascript/forms-validation/` – form validation practice
- `javascript/browser-storage/` – localStorage / sessionStorage examples
- `javascript/mini-projects/` – mini applications
- `mysql/` – SQL practice scripts
- `nodejs/` – Node.js examples
- `supabase/` – Supabase setup and client examples

## How to use

- Open any `.html` file in a browser to see the page run.
- Run `.js` files with Node.js using: `node filename.js`
- Run SQL scripts in MySQL Workbench or phpMyAdmin.
