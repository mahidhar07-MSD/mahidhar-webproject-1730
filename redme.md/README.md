# Assignment Project

This project contains HTML, CSS, and JavaScript practice files for assignments.

## Folder Structure

- `html/` – HTML practice files and the main index page
- `css/` – CSS assignment files saved as numbered examples
- `java/` – JavaScript files for exercises and tasks

## How to Use

1. Open `html/index.html` in a browser.
2. Use the links inside the page to access HTML, CSS, and JavaScript examples.
3. Modify or add more files as needed for your assignment tasks.

## Notes

- The project is designed for static web practice.
- The numbering follows the assignment sequence for easy organization.
- Files can be opened directly in any browser.

## Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>Example</title>
</head>
<body>
  <h1>Hello World</h1>
</body>
</html>
```
